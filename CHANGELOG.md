# Changelog

Alle relevanten Änderungen an dieser Extension werden in dieser Datei dokumentiert.

Das Format basiert auf [Keep a Changelog](https://keepachangelog.com/de/1.1.0/)
und dieses Projekt folgt [Semantic Versioning](https://semver.org/lang/de/).

## [2.1.0] - Unreleased

### Added

- Flipbook validity fields `valid_from`, `valid_until`, `lead_days` (default 2) and `week_label` (generated from the ISO calendar weeks, manual value wins).
- The online start (`starttime`) is derived on save from `valid_from` minus `lead_days`.
- `CurrentFlipbookResolver` service selecting the current and upcoming flipbook (completed conversions only, optional `storagePid`).
- Page cache is tagged and its lifetime capped at the next online start; saving flipbooks flushes the tag.
- Content element mode "Anzeige": show the current flipbook automatically (`tx_digitalpageflip_mode`).
- `currentFlipbook` Fluid ViewHelper (`upcoming`, `pageUid`) exposing the current or upcoming flipbook to other templates.
- The record list shows the validity period next to the title (`label_alt` `valid_from,valid_until`).
- Backend layout `DigitalPageFlipBlank` (set page TSconfig) and page object `lib.digitalPageFlip.blankPage` (`PAGEVIEW`) rendering a catalog page without the website's header, footer and assets.

### Removed

- Unused page template `Resources/Private/Templates/Page/Default.html` (replaced by `Resources/Private/PageView/Pages/DigitalPageFlipBlank.fluid.html`).

### Fixed

- `digitalpageflip:convert` now also converts hidden and scheduled flipbooks (future online start), so a prepared catalog is ready when it goes online; deleted records stay excluded.
- The content element no longer fails (HTTP 500) when there is no flipbook to show (none selected, or no current flipbook in auto mode); it renders a short notice with the configured imprint/privacy links.
- A failing page cache flush after a conversion is logged as a warning and no longer turns the completed conversion into status *Error*.
- The page cache lifetime is capped at the next online start rounded up to the full minute, matching the minute-based access time of the start time restriction.
- Documentation no longer claims that an overview of all catalogs is shown when no flipbook is selected.

## [2.0.0] - 2026-07-16

### Changed

- **BREAKING:** TYPO3 v14-only release (`^14.3`). For TYPO3 v12/v13 use the 1.x line (`^1`).
- **BREAKING:** The static TypoScript template ("Digital Page Flip") was replaced
  by the site set `kit/digital-page-flip`. Sites must declare the set as a
  dependency in their site configuration (Sites module → *Sets for this Site*,
  or `dependencies` in `config/sites/<identifier>/config.yaml`); the old
  sys_template include no longer works and must be removed.
- The content element rendering now relies on the `EXTBASEPLUGIN` definition
  auto-generated by `configurePlugin()` (including `lib.contentElement` frame
  handling); the manual legacy `USER` object was removed from the set TypoScript.
  The site set therefore declares `typo3/fluid-styled-content` as a dependency —
  the package `typo3/cms-fluid-styled-content` must be installed. The content
  element header stays suppressed (as in 1.x) via a CType-specific empty
  `Header/All` partial.
- Migrated `FlipbookDataViewHelper` from `renderStatic()` to `render()` (Fluid 5).
- Extbase model uses `Attribute\ORM` namespace with named `Cascade` argument.
- `PdfConversionService` uses the v14 `Enum\DuplicationBehavior` (class removed in v14).
- `FlipbookDataViewHelper` now skips pages whose file reference no longer exists
  (catches `ResourceDoesNotExistException`) instead of failing the page render.
- All extension settings are now defined in the site set's
  `settings.definitions.yaml` and editable in the backend via
  *Site Management > Settings* (replaces the former Constant Editor workflow);
  `constants.typoscript` was removed from the set.
- `starttime`/`endtime` are marked `searchable => false` to keep backend search
  behavior identical to the former `ctrl.searchFields` whitelist.
- Rector config raised to the TYPO3 v14 level set.

### Removed

- TCA `ctrl.searchFields` option (removed in TYPO3 v14, #106972) — replaced by per-field `searchable`.

## [1.2.0] - 2026-04-10

### Changed

- PDF-Konvertierung laeuft jetzt asynchron per TYPO3 Scheduler statt synchron beim Speichern
- DataHandlerHook setzt nur noch Status PENDING und zeigt Info-Flash-Message
- ConvertPdfCommand ist als Scheduler-Task verfuegbar (`schedulable: true`)

### Fixed

- Ghostscript Exit-Code wurde falsch gelesen — `proc_close()` liefert -1 wenn `proc_get_status()` den Code bereits konsumiert hat

## [1.1.0] - 2026-03-20

### Security

- SQL Injection Pattern in `FlipbookCleanupService::hardDeleteByField()` behoben — Raw SQL String durch `createNamedParameter()` ersetzt
- PDF-Dateigroessen-Validierung vor Konvertierung (konfigurierbar, Default: 50 MB)
- Ghostscript-Prozess nutzt jetzt `proc_open()` mit Timeout (120s) statt `exec()`

### Fixed

- FlipbookController prueft Conversion-Status — zeigt Hinweismeldung statt leerem Viewer bei nicht-fertigen Flipbooks
- DataHandlerHook erlaubt Re-Konvertierung wenn PDF bei bereits konvertiertem Flipbook ersetzt wird
- ImageMagick Exit-Code wird in `normalizePageDimensions()` geprueft und bei Fehler geloggt
- Nicht existierende `publishDate`-Tests aus FlipbookTest entfernt

### Added

- Unit Tests fuer `validateFileSize()` (8 Tests, Boundary Conditions)
- Unit Tests fuer DataHandlerHook Re-Konvertierungslogik
- Unit Tests fuer FlipbookController Status-Pruefung
